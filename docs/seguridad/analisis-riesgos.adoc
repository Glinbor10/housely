= Seguridad: análisis de riesgos y protección de datos
:toc:
:lang: es

== Datos tratados
* Nombres de pila de los compañeros (dato personal).
* Identificador anónimo de Firebase Auth por dispositivo.
* Fechas de limpieza asociadas a cada persona.
No se tratan datos de categorías especiales, ubicación ni datos de pago. El enlace a Tricount es una URL; no se accede a los gastos.

== Principios aplicados
* *Minimización:* solo nombre y actividad; sin correo ni teléfono.
* *Control de acceso:* reglas de Firestore limitadas a los miembros del piso.
* *Secretos:* las claves de cuenta de servicio viven solo en GitHub Secrets.
* *Entornos separados:* los datos de prueba van en `housely-ci`.
* *Transporte:* todo el tráfico va por HTTPS (Firebase Hosting y SDK).

== Protección de datos
El uso entre compañeros de piso entra en la actividad personal o doméstica, que el artículo 2.2.c del RGPD excluye de su ámbito. Mientras la app se use solo así, no hay obligación formal; si se abriera a terceros o se comercializara, habría que revisarlo (política de privacidad, base legal y derechos de los usuarios). No es asesoramiento jurídico.
