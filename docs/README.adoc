= Housely Documentation
:toc:
:lang: en

Project documentation tailored from https://administracionelectronica.gob.es/[Métrica v3] to a very small system: only the essential products of each process are kept, short and linked to the issues and the code.

== Approach
Métrica v3 supports two approaches: structured and object-oriented. Housely follows the *object-oriented approach (UML)*: use cases, domain model and sequence diagrams.

The implementation is *functional TypeScript*: the domain is pure functions (`src/domain`) and the model concepts (flat, member, zone, completion) are implemented as types. UML is used to model the domain; it does not require writing classes.

== Traceability
Each requirement in the catalog (`FR-xx`, `NFR-xx`) is linked to its GitHub issue, and each issue to its PR. Milestones are the iterations of the project plan.

| `NFR-xx` | Non-functional requirement
| `UC-xx` | Use case
