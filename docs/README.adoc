= Documentación de Housely
:toc:
:lang: es

Documentación del proyecto adaptada (_tailoring_) de https://administracionelectronica.gob.es/[Métrica v3] a un sistema de tamaño muy pequeño: solo se mantienen los productos esenciales de cada proceso, cortos y enlazados con las issues y el código.

== Enfoque
Métrica v3 admite dos enfoques: estructurado y orientado a objetos. Housely sigue el *enfoque orientado a objetos (UML)*: casos de uso, modelo de dominio y diagramas de secuencia.

La implementación es en *TypeScript funcional*: el dominio son funciones puras (`src/domain`) y los conceptos del modelo (piso, persona, zona, completado) se implementan como tipos. UML sirve para modelar el dominio, no obliga a escribir clases.

== Trazabilidad
Cada requisito del catálogo (`RF-xx`, `RNF-xx`) se enlaza con su issue de GitHub, y cada issue con su PR. Los hitos (milestones) son las iteraciones del plan de proyecto.
