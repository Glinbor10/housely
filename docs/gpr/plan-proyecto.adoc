== Organización
Proyecto unipersonal con tres usuarios finales. Seguimiento en el https://github.com/users/Glinbor10/projects/2[Project de GitHub]; el trabajo se agrupa en milestones.

== Hitos

[cols="1,3,3",options="header"]
|===
| Milestone | Objetivo | Productos clave

| Foundation | Base de calidad, seguridad e infraestructura | Prettier, tests de arquitectura, cobertura, CodeQL, reglas de Firestore, observabilidad
| v0.1 MVP | Uso real por los tres compañeros | Crear piso, unirse con código, enlace a Tricount
| v0.2 Polish | Experiencia completa | PWA instalable, historial y ajustes, accesibilidad e i18n
|===

== Registro de riesgos

[cols="1,3,1,1,3",options="header"]
|===
| ID | Riesgo | Probabilidad | Impacto | Mitigación

| R-01 | Reglas de Firestore mal definidas exponen datos de un piso | Media | Alto | Reglas versionadas con tests en el emulador antes de escribir código de datos
| R-02 | Superar la cuota del plan gratuito | Baja | Medio | Alerta de presupuesto y revisión periódica
| R-03 | Un compañero elige el nombre de otro | Media | Bajo | Aceptado; mejora con login de Google
| R-04 | Limitaciones de PWA en iOS (push, caché) | Media | Medio | Probar en iPhone real; push como funcionalidad opcional
| R-05 | Tricount cambia sus enlaces o no concede API | Media | Bajo | Enlace configurable; módulo de gastos propio como alternativa
| R-06 | Dependencias con vulnerabilidades | Media | Medio | Dependabot, CodeQL y `npm audit` en la release
|===
