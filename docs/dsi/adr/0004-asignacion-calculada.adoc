= ADR-0004: Asignación calculada, no almacenada
:lang: es

*Estado:* aceptada

*Contexto:* personas y zonas pueden cambiar con el tiempo.

*Decisión:* calcular la asignación de cada semana con `miembros[(semana + indiceZona) % nMiembros]` y guardar solo los completados.

*Consecuencias:* añadir o quitar personas o zonas no rompe nada y la lógica es una función pura fácil de probar (`src/domain/rotation.ts`). El historial de quién tocaba en semanas pasadas depende de los miembros activos en ese momento.
