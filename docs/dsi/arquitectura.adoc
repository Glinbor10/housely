== Visión general
Aplicación de una sola página (PWA) que habla directamente con Firebase. No hay backend propio: la seguridad se aplica con reglas de Firestore.

[source,mermaid]
----
flowchart LR
  M[Móvil: PWA React] -->|SDK| A[Firebase Auth anónima]
  M -->|SDK, tiempo real| F[(Firestore)]
  M -->|carga la app| H[Firebase Hosting]
  G[GitHub Actions] -->|despliega| H
  G -->|despliega reglas| F
----

== Capas del código

[cols="2,4",options="header"]
|===
| Carpeta | Responsabilidad

| `src/domain` | Lógica pura (rotación, completados). Sin React ni Firebase
| `src/storage` | Acceso a datos (hoy `localStorage`, después Firestore)
| `src/components` | Interfaz con MUI
|===

Las dependencias permitidas se verifican con tests de arquitectura (`src/architecture.test.ts`): el dominio no depende de componentes ni de almacenamiento, y no hay ciclos.
